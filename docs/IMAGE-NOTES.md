# Image sources and replacements

All `.webp` files in `public/images` are cropped from the **reference montage uploaded by the user** for this conversation. They're visually close to the desired page design, but because the provided montage combines numerous screenshots, many crops are not high-resolution originals. Some contain partial background lettering or borders. Replace with salon-provided, properly licensed portrait, hair, skin, spa, nail, bridal and studio photos before going live.

Image filenames identify their intended positions: `hero-salon.webp`, `haircut.webp`, `bridal.webp`, `nails.webp`, `salon-reception.webp`, etc. Full supplied reference is preserved at `docs/REFERENCE-MONTAGE.png`.
